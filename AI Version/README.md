# Employee Performance & Productivity — Full Analytics

A complete, reproducible data-analysis project over **100,000 employee records** (9 departments, 7 job titles, hires 2014–2024): exploratory analysis, equity testing, predictive modelling, an **interactive offline dashboard**, a **16-page PDF report**, a **15-slide executive deck**, and a **summary workbook** — all generated by one pipeline.

## 📌 Headline Findings

| # | Finding | Evidence |
|---|---------|----------|
| 1 | **Pay equity is healthy.** Women earn **$4.50/mo more** on average; every within-title gap is ≤ ±$25 (< 0.4%). | §Pay equity, chart `10` |
| 2 | **Salary is a formula.** Job-title premium (±$2,600) + **$493 per performance point**; model **R² = 0.991**, MAE ≈ $95. Dept, education & gender add ≈ $0. | OLS, §Salary drivers |
| 3 | **Attrition (10.0%) is statistically unpredictable** — Logistic & Random-Forest both hit **AUC ≈ 0.49** (coin flip); every segment sits within 9.5–10.3%. | charts `12`, `17`, `18` |
| 4 | **Engagement levers show zero effect.** Training, overtime, sick days, team size, remote frequency: \|r\| < 0.01 vs performance & satisfaction. | correlation matrix `06` |
| 5 | **Departments are near-identical** on every metric (salary spread $39, attrition spread 0.9 pt). | dept summary sheet |
| 6 | **Data is likely synthetic** — independent features + a near-perfect salary formula. Treat results as a validated methodology demo. | Appendix A |

## 🚀 Quick Start

```bash
pip install -r requirements.txt
python3 src/analysis.py          # EDA + models → charts/, assets/*.json
python3 src/build_dashboard.py   # → dashboard.html
python3 src/build_report.py      # → report.pdf
python3 src/build_pptx.py        # → presentation.pptx
python3 src/build_workbook.py    # → Employee_Insights.xlsx
```

Or simply run `make all`. Each build script depends only on the JSON aggregates from `analysis.py`, so you can regenerate any single deliverable in seconds.

## 🔬 Methodology

- **Profiling:** zero nulls, zero duplicate IDs; all ranges validated (age 22–60, salary $3,850–9,000, hours 30–60).
- **Descriptive & comparative:** group summaries by department, title, education, gender, tenure, remote-work level; Pearson correlation matrix.
- **Equity test:** raw and within-job-title gender pay gaps.
- **Predictive models** (scikit-learn, 80/20 stratified split, seed 42):
  - *Attrition* — Logistic Regression (scaled, C=0.5) and Random Forest (250 trees, depth 8). Accuracy 0.90 is the majority-class baseline; **AUC 0.49 reveals no signal** — reported honestly rather than cherry-picking accuracy.
  - *Salary* — OLS on 17 one-hot features; **R² 0.991**, coefficients expose the pay formula.
- **Charts:** matplotlib/seaborn, deterministic (seed 42).

## 💡 Recommendations (from the report)

1. **Protect pay equity** — automate the quarterly gap audit (already scripted).
2. **Audit performance measurement** — scores drive $493/mo per point yet correlate with nothing observable.
3. **Fix attrition data capture** — validate the `Resigned` flag; add exit-interview themes & manager ratings.
4. **Pilot before investing** — training/overtime/remote levers show zero measured effect.
5. **Keep the monitor running** — the pipeline rebuilds every deliverable in under a minute; schedule it.
